# Testimonial Starter App

A simple React application that displays a testimonial slider.

## Setup Instructions

1. Clone the repository:
    ```sh
    git clone https://github.com/moosarehan/react-learning-journey.git
    ```
2. Navigate to the project directory:
    ```sh
    cd "react-learning-journey/testimonial-starter"
    ```
3. Install dependencies:
    ```sh
    npm install
    ```
4. Start the development server:
    ```sh
    npm start
    ```

## Technologies Used
- React
- Tailwind CSS
