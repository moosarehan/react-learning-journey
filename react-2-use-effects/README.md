# React `useEffect` Examples App

A React application demonstrating the usage of the `useEffect` hook.

## Setup Instructions

1. Clone the repository:
    ```sh
    git clone https://github.com/moosarehan/react-learning-journey.git
    ```
2. Navigate to the project directory:
    ```sh
    cd "react-learning-journey/react-2-use-effects"
    ```
3. Install dependencies:
    ```sh
    npm install
    ```
4. Start the development server:
    ```sh
    npm start
    ```

## Technologies Used
- React
- CSS
