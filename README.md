# React Basics & Mini-Projects

A collection of beginner to intermediate React applications built to master hooks, components, state management, and basic UI design.

## 🚀 Projects Included

| Project | Key Concepts Covered | Tech Stack / Libraries |
| :--- | :--- | :--- |
| **Tourism Plan** | State lifting, conditional rendering, array mapping | React, CSS |
| **Top Course Finder** | Filtering, conditional styles, event handlers | React, Tailwind CSS, `react-toastify`, `react-icons` |
| **Testimonial Slider** | State navigation (Next/Prev/Surprise Me), slider state | React, Tailwind CSS, `react-icons` |
| **React Counter** | Simple state (`useState`), increments/decrements | React, Tailwind CSS |
| **Demo Shop App** | Component decomposition, form handling, props passing | React, CSS |
| **UseEffects Demo** | React component lifecycle, APIs, side-effect cleanup | React, CSS |
