# ⚛️ React Learning Journey

> A curated collection of React projects — from foundational concepts to advanced hooks — built to master modern React development one step at a time.

---

## 🗂️ Projects Overview

| Project | Description | Key Concepts | Tech Stack |
| :--- | :--- | :--- | :--- |
| [**react-hook**](./react-hook/) | Complete hands-on reference for all 12 React hooks with real-world examples. | `useState`, `useEffect`, `useContext`, `useReducer`, `useRef`, `useId`, `useTransition`, `useDeferredValue`, `useSyncExternalStore` & more | React 18, Vite |
| [**demoshopapp**](./demoshopapp/) | A demo e-commerce shop showcasing component decomposition and form handling. | Component architecture, props, form handling | React, CSS |
| [**react-2-use-effects**](./react-2-use-effects/) | Practical walkthrough of the React component lifecycle and side effects. | `useEffect`, API calls, cleanup | React, CSS |
| [**react-counter-app**](./react-counter-app/) | A simple counter app to get started with stateful components. | `useState`, event handlers | React, Tailwind CSS |
| [**testimonial-starter**](./testimonial-starter/) | An interactive testimonial slider with next, previous, and random navigation. | State navigation, conditional rendering | React, Tailwind CSS, `react-icons` |
| [**top-course-starter**](./top-course-starter/) | A course finder app with category-based filtering and toast notifications. | Filtering, conditional styles | React, Tailwind CSS, `react-toastify`, `react-icons` |
| [**tourism-plan**](./tourism-plan/) | A tourism planner app demonstrating state lifting and list rendering. | State lifting, array mapping | React, CSS |

## 🚀 Getting Started

Each project is self-contained. To run any project locally:

```bash
# 1. Navigate to the project folder
cd <project-name>

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```
